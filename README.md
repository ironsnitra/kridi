# Kridi — website

Landing page and privacy policy for **Kridi (دفتر الكريدي)**, an offline credit notebook app for shopkeepers.

Live: https://ironsnitra.github.io/kridi/ · Privacy policy: https://ironsnitra.github.io/kridi/privacy/

Plain HTML, CSS and a little JavaScript, served by GitHub Pages from `main`. There's no build step.

- `index.html`: the homepage. French and Arabic sit side by side as an open Seyès notebook. On phones, a language switch shows one page at a time.
- `privacy/index.html`: the privacy policy in French, Arabic and English.
- `assets/`: styles, demo script, favicon, share image (`og.png`, 1200×630).
- `sitemap.xml`, `robots.txt`, `404.html`

Keep the privacy policy in sync with the app. Update it (and its date) whenever the app adds a permission, a backup feature, or a new data flow.
